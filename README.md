# Peticas — esboço navegável

Protótipo estático para validar fluxos e aparência do Projeto Integrador. HTML, CSS e JavaScript, sem dependências de aplicação.

Execute `node preview.cjs` e abra http://127.0.0.1:4173.

## Fluxos

- Painel da equipe, cadastro e edição de gatos.
- Registro simulado de vacinação, comprovante e próxima dose.
- Controle demonstrativo de administrações de medicamentos.
- Candidaturas, transição de etapas, aprovação com reserva e conclusão da adoção.
- Catálogo público, entrevista em cinco etapas e acompanhamento com orientações.

## Limites do esboço

Todos os registros são fictícios e mantidos apenas na memória da página. Recarregar restaura o cenário. Não há backend, autenticação, autorização real, armazenamento de arquivos, envio de WhatsApp ou links individuais protegidos. Não inserir dados pessoais reais. Fotos, vídeos e carteirinhas dos candidatos são apenas indicados para futuro envio pelo WhatsApp. O questionário é uma adaptação inicial do material fornecido, a validar com a dona. Controles de medicação não fornecem orientação veterinária.
